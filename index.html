# doyoucode · README
개발자 테마의 Tistory 블로그 · 데스크탑 UI · Windows 11 / Linux 듀얼 모드
🪟
TIP — 데스크탑 모드 전환
우하단 관리바의 🖥️ 버튼으로 Windows ↔ Linux 모드를 자유롭게 전환할 수 있습니다.
모드별로 테마·아이콘·라벨이 자동으로 변환됩니다. ✨
💡
TIP — 전체화면 모드
우하단 관리바의 ⛶ 버튼을 클릭하면 전체화면 모드로 전환됩니다.
더욱 실감나는 데스크탑 환경을 경험할 수 있습니다! 🖥️
## 인트로 화면 (메인 첫 화면)
메인에 들어오면 데스크 일러스트가 먼저 표시됩니다
모니터 클릭 → 화면 속으로 줌인하며 데스크탑 진입 (잠시 후 개발 블로그 창 자동 열림)
PORTFOLIO 책 클릭 → 개발자 포트폴리오 사이트
Wiki 책 클릭 → 위키 사이트
데스크탑에서 우하단 🏠 버튼으로 언제든 이 화면으로 돌아올 수 있습니다
## 데스크탑 모드 (Windows / Linux)
🪟 Windows기본값 — 라이트 mica 태스크바 · 시작 메뉴 · 한글 라벨 · Chrome 풍 브라우저 · 평면 컬러 아이콘 🐧 Linux다크 우주 배경 · macOS Dock · 영문 라벨 · Astronaut / Sakura 장식 테마 활성화
선택한 모드는 브라우저에 저장되어 다음 방문 시 그대로 유지됩니다.
## 데스크탑 아이콘 (모드별 라벨 자동 전환)
📌 좌: Linux 라벨 / 우: Windows 라벨

## 시작 메뉴 (Windows 모드 전용)
좌하단 시작 버튼 클릭 → 시작 메뉴 표시
9개 앱 3열 그리드 + 사용자/전원 푸터
앱 클릭 시 해당 창 열기 + 메뉴 자동 닫힘
ESC 키 또는 외부 클릭으로 닫기
## 태스크바
Windows 모드: 실행 중인 앱만 표시 · 중앙 정렬 · 라이트 mica · 가로 막대 인디케이터
Linux 모드: macOS Dock · 호버 시 확대 · 컬러풀 그라데이션 아이콘
우측: Board 배지 · 시계 (클릭 시 캘린더 팝업)
태스크바 우클릭 → 최소화 / 복원 / 닫기 (Windows 모드는 한글)
## 터미널 명령어
ls [-l|-al]디렉토리 목록 (-l 상세, -al 숨김 포함) cd [name|..|~|-]디렉토리 이동 (..: 상위, ~: 루트, -: 이전)
└ 최하위 카테고리는 File Explorer에서 자동으로 열림 pwd현재 경로 출력 search <검색어>포스트 검색 (grep 으로도 사용 가능) date현재 날짜 및 시간 출력 echo <text>텍스트 출력 about / whoami블로그 소개 githubGitHub 프로필 열기 clear / exit터미널 초기화 / 닫기

## 브라우저 창
드래그로 이동 / 모서리로 크기 조절
뒤로 · 앞으로 · 새로고침 · 새 탭으로 열기
Windows 모드: Chrome 풍 라이트 타이틀바 · 알약형 URL바
Linux 모드: 다크 타이틀바 · traffic-light 컨트롤
## Blogram (인스타그램 스타일 사진 피드)
사진 카테고리 포스트를 Instagram UI로 감상
프로필 헤더 — 아바타 · 게시물 수 · 팔로워 · 팔로잉
3열 그리드 썸네일, 사진 클릭 시 라이트박스
라이트박스 — 좋아요 · 댓글 · 공유 링크 복사
좋아요: 로그인 / 비로그인 모두 가능 (쿠키 중복 방지)
댓글: 게스트는 이름 + 비밀번호 입력 후 작성
← → 키 또는 버튼으로 이전 / 다음 사진 이동
## Guestbook (방명록 채팅)
카카오톡 스타일 채팅 인터페이스
방문자 메시지 → 오른쪽 노란 말풍선
관리자 답글 → 왼쪽 흰 말풍선
이름 + 비밀번호 입력 후 메시지 전송
Ctrl+Enter 로 빠른 전송
## File Explorer (블로그 카테고리 탐색기)
블로그 카테고리 구조를 파일 탐색기 UI로 탐색
사이드바 트리 + 메인 영역으로 구성
Grid 뷰 / List 뷰 전환 버튼 지원
뒤로 · 앞으로 내비게이션 및 주소바 표시
폴더 클릭 → 하위 카테고리로 이동
파일(최하위 카테고리) 클릭 → 브라우저 창으로 열기
Windows 모드에선 라이트 테마 적용
우클릭 → 열기 / 속성 메뉴 사용 가능
## Links (즐겨찾기 링크 모음)
폴더별로 분류된 즐겨찾기 링크 목록
각 링크에 파비콘 자동 표시
상단 검색바로 빠른 필터링
폴더 아이콘 / 시작 메뉴 / Features 폴더에서 접근 가능
## Music Player (YouTube 기반 뮤직 플레이어)
YouTube 영상을 배경 음악으로 재생하는 플레이어
앨범 아트 · 곡 제목 · 채널명 표시
재생 / 일시정지 · 이전곡 / 다음곡 버튼
시크바로 원하는 구간으로 이동
볼륨 슬라이더로 음량 조절
플레이리스트에서 곡을 클릭하면 즉시 재생
## Board (할 일 관리 보드)
To Do · In Progress · Done 3열 칸반 보드
이슈 추가 · 수정 · 삭제 및 라벨/우선순위 관리
카드 클릭 시 상세 패널 (설명 · 체크리스트 · 기한)
드래그 앤 드롭으로 카드 컬럼 이동
클립보드 복사 — Tistory 붙여넣기 형식으로 내보내기
태스크바 Board 버튼으로 빠른 접근 · 미완료 배지 표시
## Calendar (태스크바 캘린더)
태스크바 시계/날짜 클릭 시 캘린더 팝업 표시
이전/다음 월 네비게이션
오늘 날짜 하이라이트 표시
## 우클릭 컨텍스트 메뉴 (Windows 모드는 한글 + 라이트 스타일)
배경 우클릭bash 열기 / 개발 블로그 / Theme (Linux 전용) / 튜토리얼 / 바탕화면 새로 고침 아이콘 우클릭열기 — 앱 실행 / 속성 — 앱 정보 보기 태스크바 우클릭맨 앞으로 가져오기 / 최소화 / 창 닫기 파일 탐색기 우클릭폴더 열기 · 브라우저로 열기 · 속성
## 관리자 메뉴 (메인화면 우하단)
🖥️ 모드 전환Windows ↔ Linux 데스크탑 모드 토글 🏠 메인화면으로인트로(데스크 일러스트) 화면으로 돌아가기 ⛶ 전체화면브라우저 전체화면 진입 / 종료
## 장식 테마 (Linux 모드 전용 · 바탕화면 우클릭 → Theme)
Linux 모드에서 바탕화면 우클릭 → Theme 서브메뉴로 3가지 테마 전환
Default기본 우주 배경 (별 · 달 · 우주 기지) Astronaut우주인 캐릭터 6명 — 드래그 · 던지기 · 말풍선 Sakura벚꽃 — 고양이 4마리 · 벚꽃나무 · 나비 · 말풍선
캐릭터를 드래그해서 던지면 물리 효과(낙하·바운스·걸어가기) 적용
⚠️ Windows 모드에서는 Theme 메뉴가 표시되지 않습니다. 모드를 Linux 로 전환 후 사용하세요.
테마 전환 시 던져진 오브젝트는 자동으로 원래 위치로 복귀
